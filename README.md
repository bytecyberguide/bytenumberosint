# BYTE OSINT TOOL

A powerful Python-based OSINT (Open Source Intelligence) tool for retrieving phone number details using API-based lookup.

This tool helps fetch information like:

- Full Name
- First Name
- Mobile Number
- Address
- Telecom Circle
- Email
- Alternate Number
- Record ID
- Additional Tags

Designed for fast lookup and clean terminal output with a premium ASCII interface.

---

## Features

✔ Fast phone number lookup  
✔ Clean and professional terminal output  
✔ API-based live data fetching  
✔ Error handling included  
✔ ASCII premium interface  
✔ Supports country code input  
✔ Lightweight and simple to use
